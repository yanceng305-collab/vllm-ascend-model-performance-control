# Workspace and Evidence Paths

The following server directory facts are User-approved and frozen for this project. They are path policy, not a claim that files or models are currently complete.

```text
WORK_ROOT=/data/tiankuan/zyg
MODEL_ROOT=/data/tiankuan/zyg/model
EVIDENCE_ROOT=/data/tiankuan/zyg/evidence/vllm-ascend-model-performance-control
TASK_WORK_ROOT=/data/tiankuan/zyg/work/vllm-ascend-model-performance-control
```

Codex2 must inspect only `MODEL_ROOT` for candidate model directories during Stage 0B; it must not search the entire server and must not guess a model subdirectory, revision, or download completion state. `MODEL_ROOT` model downloads may be incomplete and must be recorded as `DOWNLOAD_IN_PROGRESS` without blocking Stage 0A or a separately authorized Stage 1.

For Stage 0A/0B Evidence, use `EVIDENCE_ROOT/VLLM-ASCEND-STAGE0-SERVER-FACT-ACQUISITION/YYYYMMDDTHHMMSSZ/`, with the final component generated by Codex2 in UTC. A project-specific existing Evidence workspace may be used only when read-only inspection proves it belongs to this Control project; do not reuse another project's run directory. Do not use `/tmp` as the formal fallback. Creating the task-owned Evidence directory and writing its Evidence files is allowed bookkeeping; do not modify or delete other Evidence.

The standard container contract mounts `/data/tiankuan:/data/tiankuan` and `/home:/home`. It must never use `/data:/data` or `/root/.cache:/root/.cache`.
